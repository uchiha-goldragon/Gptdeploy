# Hwatu Showdown

Love2D 기반의 간단한 화투(고도리) 게임입니다. 플레이어와 CPU가 번갈아 가며 카드를 내고, 같은 달의 카드를 맞춰 포획하면 카드 가치에 따라 점수를 획득합니다. 모든 패를 사용하면 더 높은 점수를 얻은 쪽이 승리합니다.

## 실행 방법

1. [Love2D](https://love2d.org/) 11.x 버전을 설치합니다.
2. 본 저장소를 클론하거나 소스 코드를 내려받습니다.
3. 프로젝트 루트에서 아래 명령을 실행합니다.

```bash
love .
```

## 조작법

- **마우스 왼쪽 버튼**: 플레이어 손패 선택 및 필드 카드 선택
- **스페이스/엔터/마우스 클릭**: 타이틀 화면에서 게임 시작, 결과 화면에서 재시작
- **R 키**: 언제든 새 게임 시작
- **Esc 키**: 게임 종료

## 게임 규칙 요약

- 게임 시작 시 플레이어, CPU, 필드에 각각 8장씩 배치됩니다.
- 자신의 차례에는 손패 중 한 장을 선택해 필드와 맞추거나 그대로 깔 수 있습니다.
- 맞춘 뒤에는 즉시 더미에서 한 장을 공개하며, 같은 달을 다시 맞추면 추가로 포획합니다.
- 카드 종류에 따른 기본 점수는 다음과 같습니다.
  - 광(20점), 열끗/동물(10점), 띠(5점), 피(1점)
- 덱과 손패가 모두 소진되면 점수를 비교하여 승패를 결정합니다.

## 구조

- `main.lua`: Love2D 진입점 및 입력 처리
- `conf.lua`: 창 크기 등 Love2D 설정
- `src/cards.lua`: 48장 카드 데이터와 타입별 색상 정보
- `src/game.lua`: 게임 상태, 로직 및 렌더링 코드

간단한 규칙으로 화투를 체험할 수 있도록 구성했으며, 추가적인 족보 계산이나 애니메이션은 추후 확장 포인트로 남겨두었습니다.
